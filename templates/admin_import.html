Anleitung: Welches Format?

JSON ist die bessere Wahl, wenn die Fragen aus einem Skript oder von einer KI kommen oder wenn Texte Zeilenumbrüche, Semikolons oder Anführungszeichen enthalten. Es gibt keine Probleme mit Trennzeichen oder Zeichensätzen.

CSV ist praktisch, wenn du die Fragen in Excel oder LibreOffice pflegst. Speichere als „CSV UTF-8“ mit Semikolon oder Komma als Trennzeichen. Beides wird automatisch erkannt.

Felder

FeldPflichtBedeutung
kategoriejaName der Kategorie, Groß-/Kleinschreibung egal. Vorhanden: {% for c in categories %}{{ c.name }}{% if not loop.last %}, {% endif %}{% endfor %}
punktejaPositive ganze Zahl, z. B. 100. Eine Frage erscheint nur auf dem Spielbrett, wenn die Punktzahl zu den Punktestufen unter Einstellungen passt (Standard: 100, 200, 300, 400, 500).
fragejaFragetext, bis 2000 Zeichen.
antwortjaAntworttext, bis 2000 Zeichen.
klassenstufeneinEine Klasse (7) oder ein Bereich (7-8). Der Klassenfilter im Spiel nutzt dieses Feld.
kompetenzbereichneinFreitext, z. B. 3.3.1 Werkstoffe und Produkte (bis 200 Zeichen).
hinweisneinOptionaler Hinweis zur Frage.

Beispiel JSON

{
  "fragen": [
    {
      "kategorie": "Werkstoffe und Produkte",
      "punkte": 100,
      "klassenstufe": "7-8",
      "kompetenzbereich": "3.3.1 Werkstoffe und Produkte",
      "frage": "Nenne drei typische metallische Werkstoffe.",
      "antwort": "Stahl, Aluminium, Kupfer.",
      "hinweis": ""
    },
    {
      "kategorie": "Systeme und Prozesse",
      "punkte": 300,
      "frage": "Was ist ein Aktor?",
      "antwort": "Ein Bauteil, das eine Wirkung ausübt."
    }
  ]
}

Auch eine blanke Liste [ {...}, {...} ] ohne „fragen“ wird akzeptiert. Optionale Felder dürfen fehlen.

Beispiel CSV

kategorie;punkte;klassenstufe;kompetenzbereich;frage;antwort;hinweis
Werkstoffe und Produkte;100;7-8;3.3.1 Werkstoffe und Produkte;Nenne drei typische metallische Werkstoffe.;Stahl, Aluminium, Kupfer.;
Systeme und Prozesse;300;9;;Was ist ein Aktor?;Ein Bauteil, das eine Wirkung ausübt.;Gegenstück zum Sensor

Die erste Zeile enthält die Spaltennamen. Texte mit Trennzeichen oder Zeilenumbrüchen setzt du in Anführungszeichen ("..."). Excel macht das beim Speichern automatisch.

Regeln

  • Fehlerhafte Einträge werden übersprungen und mit Nummer und Grund aufgelistet, alle gültigen werden importiert.
  • Eine Frage mit gleichem Fragetext wie eine vorhandene gilt als Duplikat und wird übersprungen.
  • Akzeptiert werden auch englische Feldnamen: category, points, grade_level, competence_area, question, answer, hint. Unbekannte Spalten werden ignoriert.
  • Kodierung: UTF-8 (auch mit BOM). Alte Windows-Dateien (Windows-1252) werden ebenfalls gelesen.
  • Tipp: Erst mit „Nur prüfen“ testen, dann importieren. Mit dem Export sicherst du vorher deinen Fragenpool.
